2nd part, this isn't too bad to print, may take a while
Print this upside down, (with the big hole upwards.)
There is built-in support layers that need to be cut to install 
The pot.
When assembling onto the pin, make sure the potentiometer is
centered and that the two "bump stops" are 180 degrees apart.
If you need to pull out the pin, loosly thread a bolt into the 
link nut to pull it off the pot shaft.
