The first part. This is no simple part.
Print this upside down, with the narrow end up.
It has been built with a support layer over the 
hole that goes down the middle.

This is assembled with a 1/4"-20 x 2" hex bolt,
two 1-1/4" fender washers, and a 1/4-20, 7/16" x 1" link nut 

Before assembling, insert a washer in the slot in the middle.
cut the support layer in the pocket end assemble 
as follows:


bolt-washer-print(with washer inserted in middle)-linknut

The link nut should not protrude past the bottom of the post.
There should be enough space in the bottom of the link nut
for the screw of a camera mount.

It gets easier from here.
